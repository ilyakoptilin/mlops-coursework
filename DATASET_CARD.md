# Dataset Card — AI4I 2020 Predictive Maintenance

## 1. Происхождение и лицензия

* **Название:** AI4I 2020 Predictive Maintenance Dataset.
* **Источник:** UCI Machine Learning Repository (Dataset ID: `601`), URL: `[https://archive.ics.uci.edu/ml/machine-learning-databases/00601/ai4i2020.csv](https://archive.ics.uci.edu/ml/machine-learning-databases/00601/ai4i2020.csv)`.
* **Лицензия:** Creative Commons Attribution 4.0 International (CC BY 4.0).
* **Способ получения:** автоматическая загрузка скриптом `src/mlops_coursework/download_data.py` с фиксацией версий в DVC.

## 2. Состав признаков и целевая переменная

Исходный датасет содержит **10 000 записей** телеметрии промышленного оборудования (14 колонок). В итоговый набор для обучения входят 6 базовых и 3 расчётных физических признака:

| Признак | Тип | Описание |
| :--- | :--- | :--- |
| `machine_type` | Категориальный (`L`, `M`, `H`) | Класс качества/нагрузки оборудования (Low, Medium, High) |
| `air_temp_k` | Числовой (`float`) | Температура окружающей среды [K] |
| `process_temp_k` | Числовой (`float`) | Температура технологического процесса [K] |
| `rotational_speed_rpm` | Числовой (`int`) | Частота вращения шпинделя [об/мин] |
| `torque_nm` | Числовой (`float`) | Крутящий момент [Н·м] |
| `tool_wear_min` | Числовой (`int`) | Накопленный износ инструмента [мин] |
| `temp_diff_k` | Числовой (`float`, engineered) | Температурный перепад: $\text{process\_temp\_k} - \text{air\_temp\_k}$ |
| `power_w` | Числовой (`float`, engineered) | Механическая мощность [Вт]: $\tau \cdot \omega$, где $\omega = \frac{2\pi \cdot \text{rpm}}{60}$ |
| `overstrain_index` | Числовой (`float`, engineered) | Индекс перегрузки инструмента: $\text{torque\_nm} \cdot \text{tool\_wear\_min}$ |
| `target` | Бинарный (`0` / `1`) | Целевая метка отказа оборудования (`Machine failure`) |

## 3. Правила разбиения (Train / Validation / Test)

* Применяется стратифицированное разбиение `train_test_split(..., test_size=0.2, random_state=42, stratify=y)` в пропорции **80% train (8 000 записей) / 20% test (2 000 записей)**.
* Стратификация сохраняет исходную долю отказов (3.39%) в обеих выборках.
* Тестовая выборка (`20%`) изолирована и используется исключительно для финальной сравнительной оценки моделей; подбор гиперпараметров на `test` не выполняется.

## 4. Препроцессинг и защита от утечек данных

Препроцессинг реализован в едином модуле `src/mlops_coursework/features.py` (используется идентично при обучении и в REST API):

1. **Удаление идентификаторов:** исключены технические поля `UDI` и `Product ID`.
2. **Устранение утечки целевой переменной (*Data Leakage*):** удалены колонки `TWF`, `HDF`, `PWF`, `OSF`, `RNF`, которые фиксируют конкретную причину уже произошедшего отказа и недоступны в реальном времени при инференсе.
3. **Генерация физических признаков:** вычислены `temp_diff_k`, `power_w` и `overstrain_index`.
4. **Кодирование и масштабирование:** внутри `sklearn.pipeline.Pipeline` применяются `OneHotEncoder(handle_unknown="ignore")` для `machine_type` и `StandardScaler()` для числовых признаков (обучаются строго на `train`).

## 5. Ограничения и известные проблемы данных

* **Сильный дисбаланс классов:** доля отказов (`target = 1`) составляет всего **3.39%** (339 из 10 000 записей). Компенсируется использованием `class_weight="balanced"` и выбором метрик `F1-score` и `PR-AUC`.
* **Синтетическая природа данных:** датасет моделирует физические закономерности промышленного фрезерного процесса, но не содержит временных автокорреляций и деградации датчиков во времени.

## 6. Идентификаторы версий данных (DVC)

* **`v1` (сырые данные):** `data/raw/ai4i2020.csv` — метаданные и MD5-контрольная сумма зафиксированы в `data/raw/ai4i2020.csv.dvc`.
* **`v2` (очищенные данные с признаками):** `data/processed/ai4i2020_processed.csv` — метаданные и контрольная сумма зафиксированы в `data/processed/ai4i2020_processed.csv.dvc`.
